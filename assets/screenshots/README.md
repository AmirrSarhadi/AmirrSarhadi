The source revisions are recorded in each project's `SOURCE_MANIFEST.json`. Existing repository screenshots were visually reviewed before inclusion; their original test/audit claims were not rerun as part of this portfolio edit. New captures were checked for visible rendering; they are not end-to-end backend tests.

Do not add customer records, contact details, private identifiers, QR codes, access tokens or confidential floor plans to this gallery. Future screenshots should use demonstration data and include an accurate caption.
