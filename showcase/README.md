## How to read the source

The six expanded collections contain **818 complete files**. Each keeps its original path under `source/`, with a file index and a manifest containing source identity, revision and SHA-256 checksums. NewCRM comes from the uploaded archive; the other selections come from the named repositories at the recorded commits.

These collections are for code review. They intentionally omit application configuration and some dependent modules, so they are not standalone applications. Sensitive operational and proprietary implementation areas are excluded; no databases, environment files, customer uploads or production configuration are included. Existing copyright and third-party notices remain applicable; no blanket open-source license is introduced here.

## What the screenshots demonstrate

Screenshots show actual source interfaces, with individual captions identifying isolated component previews, synthetic API fixtures and existing repository captures. They do not represent live customer records or measured business results. The smart-home image shows the initial editor and does not claim a successful AI analysis.

See [image provenance](../assets/screenshots/README.md) for the capture method and source of each image group. Rendering screenshots is not a substitute for application integration tests.
